How this works
Your data
Stays here by default. Accounts are saved in this browser on this device. Optional Device sync (Settings) uploads only an encrypted vault blob to your own Worker; Discord/API/rank proxies leave the browser when you enable them. Clearing browser data wipes the vault, so use Export for backups and Import to restore or merge them.
Rank checks
Free. Refresh pulls the current rank straight from op.gg — no account, no key. If the auto-fetch is ever blocked, use Rank in a card's ⋯ menu to enter it by hand — history, the chart and the stats all work the same either way.
Layouts
Cards for browsing, the list for working through the vault a row at a time, and the wall for seeing all sixty at once — click any tile to land back on that account's card.
Cards
The bar across a card's bottom edge opens Details — flex rank, past seasons and the champions played, each folded until you click it · the star pins favorites on top · statuses mark banned/resting smurfs, banned ones are skipped by checks · tick a card's checkbox to bulk-edit status/tags or delete several at once · click a card's note to rewrite it on the spot, or its fields (honor, skins, Blue Essence…) to edit them — Fields… in the account form picks which ones, and adds your own · Card art… in the ⋯ menu sets the champion and skin behind a card.
Search
Matches names, tags, notes and skins, even ranks (try "gold"), and every word you add narrows it further. Beyond plain words it takes tier:diamond region:euw champ:yasuo (played this season, or in its top mastery) role:mid (from the last five ranked games), >plat and <gold for "at least" and "below" (<=gold takes Gold with it), and is: stale · never · flagged · banned · fav · goal · decay · ready · leveling. They combine, so >diamond is:stale is one query.
Quick find
CtrlK (or ⌘K) anywhere — type a few letters of a name or a rank to jump straight to an account, or a word like "layout", "export" or "settings" to run it. Arrows move, Enter opens.
Keys
/ search · n new account · f favorites · h streamer mode (hides Riot IDs, logins, emails and notes; its red marker in the header turns it off) · Esc closes panels · shift-click a card's checkbox to select a range.
Goals
Set a target rank in a card's Rank panel and the card grows a rail showing how far there is left, plus a rough estimate once there's a fortnight of checks to work from.
Extra privacy
Set a master password in Settings to encrypt everything at rest, plus an auto-lock timer — without the password, don't lose it, there's no recovery.
More
The ⋯ menu has bulk add (paste Name#TAGs, an op.gg multi-search link or the lobby chat), CSV import, New season (every rank into Past seasons at once, with Undo), streamer mode and Share a snapshot — a read-only page of your ranks in one link, with no logins, emails or notes in it · archive an account to hide it without deleting (toggle Archived in the toolbar) · Settings → Appearance has themes, effects, text size and what each card shows.

Rank checks
Set up your own worker — free, about 5 minutes
  1. Riot API key (optional, for ranks straight from Riot and your last 5 ranked games). Sign in at developer.riotgames.com with your Riot account. The Development API Key on your dashboard works at once but expires every 24 hours; for one that lasts, Register Product → Personal API Key. Keep the key to yourself — it is a password.
  2. Deploy to Cloudflare and sign in (a free account is enough). Keep the copy of the repo it makes private. Paste your key where it asks for RIOT_API_KEY, or leave it empty. Sync storage is set up for you.
  3. Copy the https://….workers.dev address it gives you into Backend URL above, then Save settings. The line under the field says what your worker has.
  4. Adding or replacing the key later (a development key needs this daily): Cloudflare → Workers & Pages → your worker → Settings → Variables and Secrets → RIOT_API_KEY, type Secret → Deploy.
Rather paste the code by hand? Create a Worker, paste cloudflare-worker.js, bind a KV namespace named VAULT for sync, and add the Cron Trigger 17 9 * * * for Discord alerts.
Check order: backend URL → API key → free op.gg auto-fetch. A worker with a Riot API key reads ranks from Riot directly, the most reliable source there is. With all three empty, checks use the free auto-fetch and cost nothing. The API key path (console.anthropic.com, ~1–2 ct per check) is the most reliable, but only worth it for power users.
Automatic refresh
Alerts
Needs your worker (Rank checks) and the webhook above. Your worker then keeps a short list: those accounts' Riot IDs, labels and decay estimates, never logins.
Security
Only applies while a master password is set. Off means the vault stays unlocked until you lock it.
Locks this tab immediately. Other open tabs keep their own unlock state until you reload them.
Device sync
Pushes the encrypted vault blob to your worker (KV). Same sync token on phone and PC. Last write wins. Needs a master password (Security) and a Backend URL with a KV binding (Rank checks), both above. No scrape cache — you are responsible for not hammering op.gg.
Backup
Your vault lives only in this browser. A backup file is the copy you can bring back if the browser loses it.
