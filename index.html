How this works
Your data
Stays here, apart from the Riot ID. Accounts, logins and notes are saved in this browser on this device. To read a rank, the Riot ID goes to op.gg through a public proxy (corsproxy.io, allorigins.win or r.jina.ai), or to your own Worker if you set one up. The optional extras send only what they need: Device sync uploads an encrypted vault to your own Worker, Discord alerts go to your webhook, and the AI rank check goes to Anthropic. Clearing browser data wipes the vault, so use Export for backups and Import to restore or merge them.
Rank checks
Free. Refresh reads the current rank from op.gg. No account or key needed. If that is ever blocked, enter the rank by hand with Rank in a card's ⋯ menu. History, the chart and the stats work the same either way.
Layouts
Cards for browsing, the list for working through the vault a row at a time, and the wall for seeing them all at once. Click a tile to go to that account's card.
Cards
  • Login copies the username, then the password, which clears from the clipboard after 30 seconds. The eye beside it shows the saved login.
  • The bar across the bottom edge opens Details: flex rank, past seasons and the champions played.
  • The star pins a favorite to the top.
  • A status marks a banned or resting account. Checks skip banned ones.
  • Tick cards' checkboxes to change the status or tags of several at once, or delete them.
  • Click a note to rewrite it, or a field (honor, skins, Blue Essence…) to edit it. Fields… in the account form picks which fields there are and adds your own.
  • Card art… in the ⋯ menu sets the champion and skin behind a card, and how strongly it shows.
Search
Matches names, tags, notes and skins, even ranks (try "gold"), and every word you add narrows it further. Beyond plain words it takes tier:diamond region:euw champ:yasuo (played this season, or in its top mastery) role:mid (from the last five ranked games), >plat and <gold for "at least" and "below" (<=gold takes Gold with it), and is: stale · never · flagged · banned · fav · goal · decay · ready · leveling. They combine, so >diamond is:stale is one query.
Quick find
CtrlK (or ⌘K) anywhere, then type a few letters of a name or a rank to jump straight to an account, or a word like "layout", "export" or "settings" to run it. Arrows move, Enter opens.
Keys
  • / search
  • n new account
  • f favorites
  • h streamer mode: hides Riot IDs, logins, emails and notes. Its red marker in the header turns it off.
  • Esc closes panels
  • Shift-click a card's checkbox to select a range.
Goals
Set a target rank in a card's Rank panel and the card grows a rail showing how far there is left, plus a rough estimate once there's a fortnight of checks to work from.
Extra privacy
Set a master password in Settings → Security to encrypt everything at rest, with an auto-lock timer, and unlock with Face ID, a fingerprint or Windows Hello instead of typing it. Don't lose the password: there's no recovery. The Password check-up there finds passwords used on more than one account, weak ones and, when you ask, ones in known data leaks. Sort: Last login brings up the account you last copied a login from.
More
  • The ⋯ menu has bulk add (paste Name#TAGs, an op.gg multi-search link or the lobby chat), CSV import, New season (every rank into Past seasons at once, with Undo), streamer mode and Share a snapshot (a read-only page of your ranks in one link, with no logins, emails or notes in it).
  • Archive an account to hide it without deleting it. Archived in the toolbar shows them.
  • Settings → Appearance has themes, effects, text size and what each card shows.

Advanced: your own worker or API key

A Cloudflare worker of your own reads ranks straight from Riot, and is what Device sync and Discord decay alerts run on.

Set up your own worker (free, about 5 minutes)
  1. Riot API key (optional, for ranks straight from Riot and your last 5 ranked games). Sign in at developer.riotgames.com with your Riot account. The Development API Key on your dashboard works at once but expires every 24 hours; for one that lasts, Register Product → Personal API Key. Keep the key to yourself. It works like a password.
  2. Deploy to Cloudflare and sign in (a free account is enough). Keep the copy of the repo it makes private. Paste your key where it asks for RIOT_API_KEY, or leave it empty. Sync storage is set up for you.
  3. Copy the https://….workers.dev address it gives you into Backend URL above, then Save settings. The line under the field says what your worker has.
  4. Adding or replacing the key later (a development key needs this daily): Cloudflare → Workers & Pages → your worker → Settings → Variables and Secrets → RIOT_API_KEY, type Secret → Deploy.
Rather paste the code by hand? Create a Worker, paste cloudflare-worker.js, bind a KV namespace named VAULT for sync, and add the Cron Trigger 17 9 * * * for Discord alerts.
Rank checks with your own Anthropic API key (paid)
Check order: backend URL → API key → free op.gg auto-fetch. A worker with a Riot API key reads ranks from Riot directly, the most reliable source there is. With all three empty, checks use the free auto-fetch and cost nothing. The API key path (console.anthropic.com, ~1–2 ct per check) is the most reliable, but only worth it for power users.
Alerts
Needs your own worker (Rank checks, Advanced) and the webhook above. Your worker then keeps a short list: those accounts' Riot IDs, labels and decay estimates, never logins.

Device sync
Pushes the encrypted vault blob to your worker (KV). Same sync token on phone and PC. Last write wins. Needs a master password (Security) and your own worker with sync storage (Rank checks, Advanced). There is no scrape cache, so don't hammer op.gg.

Bulk add
Paste Name#TAGs (one a line, or comma-separated), an op.gg multi-search link, or lines from the lobby chat ("Name #TAG joined the lobby"). A link brings its own region; the rest get the region below. Add logins and notes to each afterwards.
The Riot IDs are looked up on op.gg; nothing else here leaves this browser.
Protect your saved passwords

Your passwords are saved in this browser as plain text. Anyone who uses this browser, or a script running on this site, could read them.

A master password encrypts the whole vault. You enter it, or use Face ID or a fingerprint, when you open the app. It can't be recovered, so keep a backup too.
